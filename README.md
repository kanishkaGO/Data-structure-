# Data-structure-

Solving data-structure problems from basic to high level in C++.

## Linked List Practice

The repository now contains a complete linked-list implementation:

- **Singly Linked List**
  - Insert at beginning, end and index
  - Delete from beginning, end, index and by value
  - Search and update
  - Count/size and display
  - Iterative and recursive reversal
  - Find middle node
  - Find Nth node from the end
  - Remove duplicates from sorted/unsorted lists
  - Sort list
  - Palindrome check
  - Cycle creation, detection (Floyd's algorithm) and removal
  - Clear/free all nodes

- **Doubly Linked List**
  - Insert at beginning, end and index
  - Delete from beginning, end, index and by value
  - Search and size
  - Forward and backward traversal
  - Reverse
  - Clear/free all nodes

- **Circular Singly Linked List**
  - Insert at beginning and end
  - Delete from beginning, end and by value
  - Size and traversal
  - Clear/free all nodes
